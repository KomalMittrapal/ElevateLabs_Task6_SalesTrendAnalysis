# 🧾 Task 6 — Sales Trend Analysis Using SQLite   

## 🎯 Objective
Analyze monthly **revenue** and **order volume** from the *Online Sales Data* dataset using SQL aggregate and date functions.  
The analysis demonstrates use of date extraction, grouping, and aggregation to identify monthly trends and top-performing periods.

## 🧩 Tools & Functions Used
- **Tool:** SQLite  
- **Functions Used:** `strftime()`, `SUM()`, `COUNT(DISTINCT)`, `ORDER BY`, and date filtering with `BETWEEN`.  
- **Concepts Practiced:**  
  - Extracting year / month from a date field.  
  - Grouping data by month and year.  
  - Summing revenue and counting unique orders.  
  - Sorting results by revenue.  
  - Limiting analysis to a specific time range.

1. Monthly Trends: Identified peak and low-revenue months.

2. Order Volume: Observed variations in customer activity across months.

3. Top Months: Determined the highest-revenue months.
